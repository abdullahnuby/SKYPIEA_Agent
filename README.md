# Device Agent 🤖

Agent محلي بيشتغل على جهازك، مربوط بأي LLM، وبتكلمه من تيليجرام.

بيقرأ ويكتب ملفات، ينفّذ أوامر PowerShell، يفتح مواقع بمتصفح حقيقي،
يقرأ ويبعت إيميل، ويشتغل لوحده في مهام مجدولة — وكل خطوة خطيرة بتستنى موافقتك بزرار.

**وشغّال بدون أي موديل مدفوع:** عقله مكتبة مهارات عربية جاهزة + أوامر بتعلّمهاله ويحفظها
+ موديل صغير بيتدرّب على جهازك من أوامرك (بدون GPU ولا إنترنت).

---

## طريقتين للعقل

| الوضع | `AGENT_MODE` | إيه اللي بيحصل |
|---|---|---|
| 🧠 **قواعد + تعلم** | `rules` | يفهم أوامر عربية بمطابقة ذكية، ويتعلم أوامر جديدة منك — بدون إنترنت وبدون فلوس |
| 🤖 **موديل لغوي** | `llm` | يفهم أي صياغة، يخطط خطوات، ويصلّح غلطه — محتاج مفتاح API |
| 🔀 تلقائي | `auto` | لو فيه مفتاح يستخدم الموديل، غير كده يرجع للقواعد |

القواعد بتغطي: فتح البرامج والروابط، الملفات، البحث، الإيميل، المتصفح،
السكرين شوت، معلومات الجهاز، الحساب، والأخبار.

**Learn by teaching** — أي أمر مش موجود، علّمهوله مرة واحدة:

```
/learn افتح الشغل => start "" "C:\Work"
/learn قولي حالتك => رد: تمام يا فندم
```

بعد كده «افتح الشغل» من أي صياغة قريبة هتشتغل فورًا، ومحفوظة في قاعدة البيانات.

## الموديل الصغير (اللي بيتدرّب على أوامرك)

جوه `agent/train/` فيه موديل حقيقي بيتدرّب محليًا في **ثواني**:

| البند | التفاصيل |
|---|---|
| المدخلات | كلمات + ثنائيات كلمات + مقاطع حروف (3-grams) بتوقيع hashing |
| الموديل | انحدار لوجستي (softmax) بـ **numpy فقط** — بدون PyTorch |
| الحجم | 2048 × 22 وزن — ملف `data/intent_model.npz` أقل من 300KB |
| الكوربوس | **1,407 صياغة** لـ 22 نية (قوالب × كائنات + تنويع) |
| التدريب | 3,575 مثال بعد التنويع — دقة اختبار **98.0%** |
| التشغيل | أقل من ميلي ثانية على المعالج |

**إزاي بيتركب في العقل؟** الترتيب خمس مراحل:

1. أوامر علّمتها بنفسك (مطابقة دقيقة)
2. مهارات Markdown اللي ضفتها في `skills/`
3. مهارات regex الجاهزة
4. تشابه ضبابي مع الأوامر المتعلَّمة
5. **الموديل** — لما كل اللي فوق يفشل، يتوقع النية من الصياغة

بعد كده بيروح للأداة المناسبة. مثال حقيقي:

```
ممكن تفتحلي يوتيوب؟   → open → https://youtube.com
الهارد فاضل فيه كام    → disk
نسبة البطارية كام      → battery
```

**بوابات الأمان (درجتين):**

| نوع النية | الشرط | ليه |
|---|---|---|
| أوامر بتعمل حاجة على الجهاز | احتمال ≥ 0.15 **و** فرق ≥ 0.30 | ماننفّذش حاجة غلط |
| ردود كلامية (تحية/تعريف/وقت/مساعدة) | احتمال ≥ 0.15 **و** فرق ≥ 0.15 | أسوأ حالة رد غلط، مش عملية |

اتجرّب على **27 صيغة جديدة** مالها وجود في التدريب: **26 صح** (96%)،
و**23** بيعدّوا بوابة الثقة. وعلى **30 جملة خارج النطاق**: صفر أوامر خطيرة
اتنفّذت — اللي عدّى كان 3 تحيات/سؤال شخصي ورد البوت عليهم رد كلامي عادي.

**إعادة التدريب** بعد ما تضيف أوامر جديدة:

```
/train
```

أو من التيرمنال:

```powershell
.\.venv\Scripts\python.exe -m agent.train.train
```

> **بصراحة:** ده **مصنّف نوايا** مش موديل لغوي توليدي. بيفهم صيغ أوامر جديدة،
> لكنه ما بيكتبش كلام ولا بيخطّط خطوات. ده الحد اللي جهاز بـ 8GB وبدون GPU يقدر عليه فعلًا.

## التشغيل في 5 دقايق

### 1) اعمل بوت

1. افتح [@BotFather](https://t.me/BotFather) → `/newbot` → خد التوكن.
2. افتح [@userinfobot](https://t.me/userinfobot) → خد الـ **Id** بتاعك.

### 2) الإعدادات

```powershell
cd "C:\path\to\device-agent"
Copy-Item .env.example .env
notepad .env
```

املأ على الأقل:

```env
TELEGRAM_BOT_TOKEN=123456:AA...
TELEGRAM_ALLOWED_CHAT_IDS=123456789
LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=sk-...
LLM_MODEL=gpt-4.1-mini
```

> **مهم:** سيب `APPROVAL_MODE=ask` في البداية. متخليهاش `auto` غير لما تبقى فاهم كل أداة بتعمل إيه.

### 3) التشغيل

```powershell
.\run.ps1
```

أول مرة هيعمل `.venv` ويثبّت `httpx`، وبعدها يبدأ يستقبل من تيليجرام.

### 4) فحص قبل ما تبدأ

```powershell
.\.venv\Scripts\python.exe -m agent.main --check
```

بيختبر: مجلد العمل، التوكن، اتصال تيليجرام، والموديل.

### 5) جرّب

ابعت للبوت:

```
عايز تعمل ملف اسمه hello.txt فيه "أهلاً"
```

هيطلب موافقة → اضغط ✅ → الملف يتعمل في `workspace/`.

## ليه مش دربنا GPT من الصفر؟

فيه ريبو تعليمي ممتاز — [how-to-train-your-gpt](https://github.com/raiyanyahya/how-to-train-your-gpt) —
بيبني GPT بـ PyTorch خطوة بخطوة. اطّلعنا عليه، وفيه فرق جوهري بينه وبين اللي محتاجينه:

| | الريبو | اللي الـ agent محتاجه |
|---|---|---|
| المخرج | إكمال نص (text completion) | قرار: أي أداة وبأي معاملات |
| الحجم | 17M parameters (نسخة تجريبية) | مليارات + تدريب على تريليونات توكنز |
| البيانات | كوربوس صغير إنجليزي | أوامر عربي + tool calling + محادثات |
| العتاد | CPU لنسخة مصغّرة | GPU (أسابيع) |

جهازك (8GB RAM، Intel HD 520، ~5GB فاضي) يقدر يدرّب نسخة صغيرة **كتمرين تعليمي**،
لكن الناتج هيكتب جُمل مكسّرة — ومش هيعرف ينادي أداة ولا يخطّط خطوة.
عشان كده اخترنا الحل اللي بيشتغل فعلًا على العتاد ده: **مصنّف نوايا متدرّب محليًا**
(شوف القسم فوق) + مكتبة مهارات. لو عايز تجرّب الريبو للتعلم، أنسب مكان هو
Google Colab بجلسة GPU مجانية.

## الذاكرة الشخصية 🧠

الـ agent بيسجّل المحادثات كلها في SQLite، وبيستخرج منها معلومات ثابتة عنك
ويحفظها في جدول `facts` — ويستخدمها بعد كده في الردود وفي تحيته ليك.

**إزاي تعلّمه عنك؟** مفيش أمر مطلوب — اتكلم عادي:

| تقول | يخزّن |
|---|---|
| `اسمي عبدالله` | الاسم |
| `أنا من القاهرة` / `ساكن في الجيزة` | المدينة |
| `بشتغل في شركة بيانات` / `أنا مهندس` | الشغل / الوظيفة |
| `بحب القهوة السادة` / `مش بحب الزحمة` | تفضيلات |
| `بستخدم كروم` / `مشروعي متجر إلكتروني` / `هدفي أتعلم بايثون` | استخدامات / مشروع / هدف |
| `مهتم بالذكاء الاصطناعي` | اهتمام (بيتأكد لما يتكرر في يوم تاني) |
| `افتكر إن شغلي بيبدأ 9 الصبح` | ملاحظة صريحة |

وبعدها اسأله: **«انت فاكر ايه عني؟»** أو **«اسمي ايه؟»** أو **«احنا كنا بنتكلم عن ايه؟»**.

- `/facts` — يعرض كل اللي فاكره عنك (وكل معلومة ليها رقم).
- `/recall شغلي` — استرجاع ذكي عن موضوع معيّن.
- `/profile` — يكتب بروفايلك في `data/profiles/<chat_id>.md`.
- `/forget_fact 12` — يمسح معلومة بالرقم.
- أول رسالة منك على تيليجرام: بياخد `first_name` بتاعك ويحفظه كاسم — تقدر تغيّره بـ `اسمي ...`.
- **الأسرار مش بتتحفظ:** أي كلام فيه باسورد / كلمة سر / OTP / CVV / بطاقة بيترفض بوضوح.
- في وضع الـ LLM: المعلومات دي بتتحقن في الـ system prompt، فالموديل بيرد وهو عارفك.

### الذاكرة المنظّمة (v2)

كل معلومة بقت ليها **بُعد** (identity / preference / activity / decision /
relationship / methodology)، و**دليل** (نص الرسالة الأصلي)، و**مستوى ثقة**،
و**حالة** (`active` / `pending` / `superseded` / `dormant` / `forgotten`).

| السلوك | التفاصيل |
|---|---|
| تصحيح معلومة | القيمة القديمة بتتحول `superseded` مش بتتمسح — عندك تاريخ تغيّر |
| معلومة ضعيفة | بتفضل `pending` لحد ما تتكرر في **جلستين مستقلتين** (يومين) |
| استرجاع | بيفهم نية السؤال (هوية/تفضيل/نشاط/قرار/طريقة) ويرتّب بالثقة + التطابق + الحداثة |
| تقادم | الهوية والتفضيلات والعلاقات معفاة. النشاط/القرارات بتنام بعد 90 يوم وتُنسى بعد 180 |
| تنظيف يومي | بيحصل تلقائيًا كل يوم، وتقدر تشغّله فورًا بـ `/consolidate` |
| بروفايل | ملف Markdown مقروء تقدر تعدّله أو تشاركه |

### قواعد السلوك (بتتعلم من تصحيحك)

مش محتاج أمر — لو قلت:

```
من دلوقتي ردودك تكون مختصرة
متعملش تفتح ملفات من غير إذن
لا، المفروض تقولي الأول
```

هيحفظها كقاعدة ويعرضها بـ `/rules`، ويمسحها بـ `/forget_rule <رقم>`.
قواعد الاختصار ومنع الإيموجي بتتطبق فعليًا على الردود.

**مسح بالمعلومة نفسها:** `انسى المدينة` — `امسح معلومة القهوة` — `شيل معلومة الاسم`.

**متابعة الأوامر (سياق قصير المدى):**

| تقول | يعمل |
|---|---|
| `كرر` / `تاني` | يعيد آخر أمر |
| `افتحه تاني` | يفتح نفس آخر حاجة اتفتحت |
| `وافتح كمان جوجل` | يفتح جوجل بعد الأمر اللي قبله |
| `يا عبدالله افتح يوتيوب` | يشيل النداء بالاسم ويكمّل |

## اختبار المحاكاة (100 ألف سيناريو) 🧪

فيه بيئة محاكاة داخلية معزولة في `tests/sim/` — مابتلمسش جهازك ومابتشغّلش أدوات
حقيقية: بتسجّل اسم الأداة والمعاملات وقرار السياسة بس، وبتستخدم SQLite في الذاكرة
ومجلد عمل وهمي.

- 17 عائلة سيناريو: حقائق شخصية، استرجاع، فتح/بحث/حساب/ملفات/معلومات النظام،
  كلام عادي، خارج النطاق، ضوضاء (همزات/تاء/أخطاء/إيموجي)، أمان، حالات حدية،
  محادثات متعددة الأدوار، تصحيح معلومات، ومسح.
- كل سيناريو بيتحقق من: الأداة المتوقعة، قرار السياسة (allow/ask/deny)، الرد،
  والحقائق اللي اتخزنت.
- التشغيل:

```powershell
python tests/sim/run.py --n 100000 --seed 7 --workers 8
```

بيكتب تقرير `data/sim_report.md` + JSON، وفيه نسبة النجاح لكل فئة وأمثلة الفشل.
النتيجة الحالية: **100,000 سيناريو / 112,499 دور — 0 فشل** على بذرتين مختلفتين.

> **ليه الذاكرة مش جزء من الـ GPT؟** مفيش موديل لغوي «بيفتكر» لوحده — الذاكرة دايمًا
> طبقة منفصلة (قاعدة بيانات + استرجاع) بتتحقن في السياق. ده اللي بتعمله المساعدات
> التجارية بالظبط: الموديل بيفهم، والذاكرة بتفتكر. عشان كده الريبو التعليمي لوحده
> مبيعملكش agent شخصي، والموديل الصغير اللي بندرّبه هنا هو «الفهم» — والذاكرة دي هي «افتكرني».

## التكامل مع ethan-agent 🔗

اطّلعنا على [llm011/ethan-agent](https://github.com/llm011/ethan-agent) — agent
شخصي Python كامل. المشروع ده بيعتمد على LLM مدفوع (Claude/OpenAI) وPython 3.12+
وواجهات desktop/web، فمش ممكن ناخده كما هو على جهاز 8GB بدون GPU. بدل كده
أخدنا **المعمارية** اللي بتنفع، وزرعناها في العقل القائم على القواعد:

| الفكرة في Ethan | اللي اتعمل عندنا |
|---|---|
| ذاكرة منظّمة بـ 64 بُعد + مستخرِج LLM | 23 مفتاح عربي → بُعد، باستخراج قواعدي بدون LLM |
| Admission حتمي: explicit / observed / inferred / corrected | نفس المستويات، مع ترقية بعد جلستين مستقلتين |
| كل ذكرى لازم لها quote من الرسالة | عمود `quote` بيتخزن ويتعرض في البروفايل |
| Supersede بدل الحذف | `status=superseded` + `superseded_by` — تاريخ محفوظ |
| Decay Tier A/B/C | الهوية/التفضيلات/العلاقات معفاة، والباقي 90/180 يوم |
| Recall بنية السؤال + RRF | تصنيف نية عربي + ترتيب بالثقة والتطابق والحداثة |
| Playbook قواعد من التصحيح | جدول `procedures` + `/rules` + تطبيق فعلي |
| مهارات `SKILL.md` بـ YAML | نفس الصيغة في `skills/` — إضافة مهارة بدون كود |
| Cron عبر APScheduler | محلل cron خماسي خاص بنا + `/cron` |
| Loop control (3/2/2) | نفس العتبات: 3 تكرارات، 2 أخطاء، محاولتين reflection |
| Tool metadata (fast_path/cacheable) | `side_effect` / `cacheable` / `no_compress` + `/tools` |
| `user_profile.md` | `data/profiles/<chat_id>.md` |

**اللي اتساب عمدًا:** الاعتماد على LLM مدفوع، Python 3.12+، تطبيق Desktop،
واجهة Web، ACP، إضافة المتصفح، القنوات المتعددة (Slack/Discord/WeChat)،
وEmbeddings/Vector DB. كلها إما مش متاحة على العتاد ده أو مش محتاجينها.

**الاختبارات:** `tests/ethan_port_test.py` — 58 فحص للذاكرة والأدلة والترقية
والتقادم والاسترجاع والقواعد والبروفايل والمهارات وcron وحماية الدوران.

| `email_send` | إرسال إيميل | ✅ دائمًا |
| `browser_open` / `click` / `fill` / `text` / `screenshot` | متصفح حقيقي | تلقائي |

أوامر زي `format c:` و `diskpart` و `shutdown` و `reg delete` **مرفوضة نهائيًا**

## الأمان — اقرأ الجزء ده

1. **`TELEGRAM_ALLOWED_CHAT_IDS` هو خط الدفاع الأول.** لو فاضي، البوت بيشتغل
   لأي حد يعرف اسمه. الكود بيرفض التشغيل لو القائمة فاضية.
2. **التوكن = كلمة سر الجهاز.** لو اتسرب، اعمل `/revoke` من BotFather فورًا.
3. **`APPROVAL_MODE=auto` خطر.** معناه مفيش تأكيد بشري قبل تنفيذ الأوامر.
4. **مفيش sandbox حقيقي.** الأوامر بتشتغل بصلاحيات حسابك.
   لو عايز عزل حقيقي: شغّله جوه WSL2 أو VM، أو خلي `WORKSPACE` مجلد منفصل.
5. **الإيميل:** استخدم **App Password** (Gmail) مش كلمة السر الأصلية.
6. **سجل التدقيق** في `data/agent.db` (جدول `audit`) و`data/audit.log`.

## توسعات سهلة

- **أداة جديدة:** ملف في `agent/tools/` + `@tool(...)` — تتسجل تلقائيًا.
- **واتساب بدل تيليجرام:** نفس `Dispatcher` مع أي واجهة تانية.
- **Webhook بدل polling:** أسرع وأخف لو عندك دومين.
- **تلخيص المحادثات الطويلة:** ضغط الرسايل القديمة في ملخص لكل فترة (episodic memory).
